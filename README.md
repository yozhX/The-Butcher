## Installation
### 1. Download
* Download the `.jar` file.
* Press Windows + R, type `%appdata%` and hit Enter.

### 2. Setup
* Move or copy the `.jar` file into the `.minecraft/mods` folder.
* (You can delete any older versions of the mod if you have them installed).*
